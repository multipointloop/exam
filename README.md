## 📖 项目简介

長門番堂是一个二次元动漫周边商城，设计风格致敬 [yuc.wiki](https://yuc.wiki/)（長門有C的新番导航站），采用极简、内容优先的wiki风格，同时完整实现了电商核心功能。

## ✨ 功能特性

### 核心功能
- **首页** — 轮播图Banner、商品分类导航、搜索功能、商品网格展示、畅销排行榜（yuc.wiki表格风格）
- **登录/注册** — 表单合法性校验（用户名、邮箱、手机号、密码格式验证）、Tab切换
- **商品详情页** — 商品大图、规格参数、价格信息、数量选择、加购/立即购买、相关信息表
- **购物车** — 商品列表、数量修改、删除商品、价格汇总
- **结算页面** — 收货信息填写、配送方式选择、支付方式选择、订单汇总、提交订单
- **个人中心** — 个人概览（订单统计、消费统计）、编辑资料、安全设置（修改密码）、积分系统
- **订单管理** — 订单列表、状态筛选（待付款/已付款/运输中/已完成/已取消）、订单操作（付款/取消/确认收货/再次购买）

### 数据管理
- 商品具有增删改查（CRUD）功能
- 搜索支持商品名称、分类、标签、描述
- 排序支持综合、销量、评分、价格、上架时间
- 数据使用 localStorage 持久化存储
- Ajax/JSON 异步数据加载（模拟）

## 🛠️ 技术栈

| 技术 | 说明 |
|------|------|
| HTML5 | 语义化标签、表单验证属性 |
| CSS3 | Grid/Flexbox布局、CSS变量、动画、响应式设计 |
| JavaScript (ES6+) | 类、Promise、箭头函数、模板字符串 |
| JSON | 商品数据结构化存储与传输 |
| Ajax (模拟) | 异步数据获取（Promise + setTimeout） |
| localStorage | 购物车、用户、订单数据持久化 |
| 响应式设计 | 桌面端/平板/手机三端适配 |

## 🎨 设计理念

致敬 yuc.wiki 的设计风格：
- **极简主义** — 纯白背景，大篇幅留白
- **内容优先** — 表格驱动布局，信息密度高
- **Wiki风格** — 结构化信息展示，无冗余装饰
- **高效导航** — 分类标签、面包屑、搜索

在此基础上融入电商元素：
- 柔和的卡片式商品网格
- 简洁的交互反馈（Toast提示、微动画）
- 完整的购物流程闭环
